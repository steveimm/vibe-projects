# Onboarding demo

The optional demo opens Android Settings through the same server and model configured for normal tasks. It first checks accessibility, overlay permission, and server configuration. A revoked permission returns to its setup step. Missing server settings return to Model server.

A successful task records the demo outcome and advances to Complete. Failure shows the error with retry, server-settings, and skip actions. Going back or skipping cancels the demo session. There is no provider login or credential-specific demo path.
